# 03 — ATURAN BILINGUAL

Kebijakan lengkap ada di [`../phase-0/08_I18N_FALLBACK_POLICY.md`](../phase-0/08_I18N_FALLBACK_POLICY.md).
Dokumen ini adalah aturan praktis sehari-hari.

---

## 1. Dua jenis teks

| Jenis                                                  | Sumber                                  | Boleh kosong?                         |
| ------------------------------------------------------ | --------------------------------------- | ------------------------------------- |
| **String UI** — tombol, nav, judul bagian, pesan error | `messages/id.json` & `messages/en.json` | **Tidak.** Kunci hilang = build gagal |
| **Konten dinamis** — judul dokumen, isi SOP            | Kolom database `*Id` / `*En`            | Boleh. Berlaku aturan fallback        |

---

## 2. Menambah teks UI

**Setiap kali** menambah teks yang dilihat pengguna:

1. Tambahkan kunci di `messages/id.json`
2. Tambahkan kunci yang **sama** di `messages/en.json`
3. Pakai lewat `useTranslations` / `getTranslations`

```tsx
// ❌ tidak akan lolos pemeriksaan
<button>Unduh CV</button>

// ✅ Server Component
const t = await getTranslations('common')
<button>{t('downloadCv')}</button>

// ✅ Client Component
const t = useTranslations('common')
<button>{t('downloadCv')}</button>
```

Menambah kunci hanya di salah satu berkas akan menggagalkan build. Itu disengaja.

---

## 3. Penamaan kunci

Struktur bersarang mengikuti area, bukan mengikuti halaman:

```json
{
  "common": { "downloadCv": "…", "readMore": "…", "backToTop": "…" },
  "nav": { "home": "…", "projects": "…", "knowledge": "…" },
  "home": { "hero": { "headline": "…", "summary": "…" } },
  "knowledge": { "type": { "sop": "…", "lab": "…" } },
  "form": { "error": { "required": "…", "invalidEmail": "…" } }
}
```

Aturan:

- camelCase, maksimal 3 tingkat.
- Nama kunci menggambarkan **makna**, bukan tampilan: `submitLabel` ✅, `blueButton` ❌.
- Teks yang dipakai di ≥ 2 tempat masuk ke `common`.

---

## 4. Nilai dinamis

```json
{ "resultCount": "{count, plural, other {# dokumen}}" }
```

```tsx
t('resultCount', { count: 12 })
```

**Jangan pernah** merangkai kalimat dari potongan:

```tsx
// ❌ mustahil diterjemahkan dengan benar
{
  t('found')
}
{
  count
}
{
  t('documents')
}
```

Urutan kata berbeda antar bahasa. Kalimat yang dirangkai akan salah di salah satunya.

---

## 5. Tanggal dan angka

```tsx
const format = await getFormatter()
format.dateTime(project.publishedAt, { dateStyle: 'long' })
```

Jangan merakit tanggal manual (`${d.getDate()}/${d.getMonth()+1}`). Selalu format di **Server Component** dengan zona waktu tetap `Asia/Jakarta` — memformat di klien akan menghasilkan hydration mismatch bagi pengunjung di zona waktu lain.

---

## 6. Konten dinamis dari database

Ada helper untuk memilih field sesuai locale dengan fallback:

```ts
import { pickLocale } from '@/lib/i18n-content'

const title = pickLocale(doc, 'title', locale)
// locale 'en' + titleEn ada    → titleEn
// locale 'en' + titleEn kosong → titleId
// locale 'id'                  → titleId
```

**Jika isi yang dirender berbeda bahasa dari locale halaman, wajib dibungkus `lang`:**

```tsx
<div lang="id">{content}</div>
```

Tanpa ini, screen reader membacakan teks Indonesia dengan fonetik Inggris. Ini persyaratan WCAG 3.1.2, bukan penyempurnaan.

Halaman EN yang isinya masih Indonesia juga **wajib** menampilkan banner `translation.pending` di atas isi.

## 7. Tautan

Selalu pakai `Link` dari `@/i18n/navigation`, bukan dari `next/link`:

```tsx
// ❌ kehilangan awalan locale
import Link from 'next/link'
<Link href="/projects">

// ✅ otomatis menjadi /id/projects atau /en/projects
import { Link } from '@/i18n/navigation'
<Link href="/projects">
```

Ini adalah kesalahan nomor satu dalam proyek next-intl. Tautan tanpa locale akan melempar pengguna kembali ke bahasa default di tengah penelusuran.

---

## 8. Antarmuka admin

`/admin/*` **hanya bahasa Indonesia.** Teks boleh ditulis langsung di JSX di sana.

Alasan: hanya satu orang yang memakainya. Menerjemahkan CMS menggandakan pekerjaan tanpa manfaat.

Yang tetap bilingual di admin: **field konten** (judul ID/EN, isi ID/EN) — itu data, bukan antarmuka.

---

## 9. Checklist sebelum PR

- [ ] Setiap kunci baru ada di `id.json` **dan** `en.json`
- [ ] Tidak ada teks langsung di JSX pada rute publik
- [ ] Tidak ada kalimat yang dirangkai dari potongan
- [ ] Semua `Link` berasal dari `@/i18n/navigation`
- [ ] Tanggal diformat lewat `getFormatter`, bukan manual
- [ ] Isi berbeda bahasa dibungkus atribut `lang`
- [ ] Sudah dibuka di `/id` **dan** `/en`
- [ ] Tata letak tidak rusak oleh teks Indonesia yang lebih panjang

Poin terakhir sering terlewat: teks Indonesia rata-rata 15–20 % lebih panjang. Tombol yang pas di bahasa Inggris bisa terpotong di bahasa Indonesia.
